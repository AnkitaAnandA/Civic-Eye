# Test photos

Place your own JPG, JPEG, PNG or WebP photos here (each under 5 MB).
Use a pothole photo, a garbage photo, an unrelated photo and a streetlight photo.
No test photographs have been fabricated or copied into this folder.
Avoid people, number plates, private information and copyrighted photos you lack permission to use.
Demo mode always produces a simulated pothole example regardless of the photo;
it is not a classifier and cannot test visual accuracy.
